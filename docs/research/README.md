# The research

This folder keeps one written study for each research question of coeval. A study compares the theory and the known systems of its field with the kernel. It ends with proposals, ranked by value for effort. A study changes no rule. The roadmap (`docs/ROADMAP.md`) takes up each proposal as a row, with a reference to the study and the proposal, for example (R3 P5).
