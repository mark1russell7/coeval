coeval is a base for declarative languages. Each language stores its programs as JSON documents. coeval gives the parts that all of these languages share. These parts are the documents, the ladder that finds an evaluator and the context of a term. They are also the split between pure work and effects, and one merge of languages.

Each idea has a page with a live diagram. The diagrams use the kernel of the repository, thus each answer comes from real code.

## The whole model in one loop

A store holds documents. The derive side computes the view from the store, without an effect. An event starts a run, and a run causes effects in a written order. The effects change the store, and the loop starts again.

## Use the kernel

The kernel is on npm as `@mark1russell7/coeval`. Its API is not stable before version 1.0.

```sh
npm install @mark1russell7/coeval
```

```ts
import { STD_MACHINE, prepare } from "@mark1russell7/coeval";

const plan = prepare(STD_MACHINE, { type: "add", value: [2, { type: "multiply", value: [3, 4] }] });
plan.evaluate(); // { ok: true, value: 14 }
```

`prepare` compiles the document one time into a plan. A plan evaluates many times, and an error comes back as a value with a code and a place. The [decisions](./design/decisions/) and the [research](./design/research/) tell why the kernel works this way.
