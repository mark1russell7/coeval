The evaluator of `if` shows why an evaluator gets its parts sealed and not evaluated. It evaluates the test first. Then it evaluates only the branch that the test selects. The other branch is not evaluated, and its card says so.

The context has the name `size` with the value 12. Thus the test is true, and the log in the other branch does not happen.

## Each evaluator decides

A condition is not a special part of the language. It is a kind with an evaluator, as `add` is. Any evaluator can decide which parts to evaluate, how many times, and in which context. A loop, a retry and a handler that waits for an event are evaluators of the same form.
