A sequence evaluates its steps in their written order. A step with a name tag gives its result to the later steps under that name. A reference reads a name back. This is the scope of `let*`: each binding sees the bindings before it.

## The context grows

Select the steps one after the other, and look at the panel. Step 1 can read no name. Step 2 can read `a`. Step 3 can read `a` and `b`. The sequence makes the context larger after each named step. A reference to a later name gives `#NAME?`, because that name does not exist yet.

## A name and a nesting are two forms of one thing

A sequence with names is the same as nested bindings: `let a = 1 + 2 in let b = a * 10 in log b`. The sequence writes the nesting as a list, so that a person reads it from the top to the bottom.
