A reference is a document of the kind `ref`. Its value is a path: a list that starts with a root of the context, then one step for each hop.

```json
{ "type": "ref", "value": ["names", "cards", "ids", 1] }
```

## Five roots

The context is a record with five roots. Each path starts at one of them.

| Root | What it holds | Who sets it |
| --- | --- | --- |
| `self` | The node that the term is part of | A node of a tree sets it for its parts |
| `names` | The values that the evaluators around the term bound | A sequence adds `last` and the name of each step |
| `world` | The registry of kinds | The host of the evaluation |
| `event` | The event that started a run | A handler |
| `caps` | The effects that the term can cause | Each evaluator gives the same set or a smaller set |

The evaluators differ in how they change the context for their parts. The references do not differ: each reference is a walk from a root.

## Each step is a question

A step does not carry a meaning of its own. The walk asks the thing that it reached: "what is this key on you?" The question goes up the ladder of the verb `deref`.

- **Own:** a node of a tree answers itself. It answers `parent` with the node that holds it, as any other field. A field of a node evaluates when the step reads it.
- **Kind:** a kind can name a `deref` evaluator for its documents.
- **Default:** a record answers with a field, and a list answers with an item.

A step can also be a document. Then the walker of its kind takes the step. `nearest` is such a kind: it follows `parent` until it reaches a node of a type. With `self: true`, the node where it starts counts too. It is not special. It is a kind with an evaluator.

After each hop, the walk examines what it reached. When that is a reference, the walk follows it until it reaches something else. This is collapse. A cycle of references gives `#CYCLE!`.

## A type is a path too

The type of a document is a reference into the world: `"add"`, or `["math", "product"]`. A namespace groups kinds, and an alias is a reference to another kind. The walk follows an alias by collapse. A text or a list of keys in the field `type` is a base reference that the kernel resolves itself. Thus the chain of types stops there, and it does not expand forever.

The world of a sandbox is smaller. A path that the world cannot resolve gives `#KIND?`. Thus the reach of a term is what its world and its context can name.

## Shorter forms are possible

A language on top of coeval can accept a shorter form, for example the text `$parent.width`. Its evaluator changes the short form into a path. The stored document always has the full path with its root, thus no reader guesses.
