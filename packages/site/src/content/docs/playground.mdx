## How to build

1. Select a starting document, or keep the one that is there.
2. Select a card. The panel shows its kind, its value and its name.
3. Change the kind to replace the card with a new document of that kind.
4. Select **Add a part** to add a part to a list. Select **Put in a list** to nest the card one level deeper.
5. Select **Step through it** to see each event of the evaluation.

## The text

The text pane shows the document as a formula, for example `2 + 3 * 4`. Change the text. After a short wait, the picture shows the new document.

- A text with a problem does not change the picture. The pane shows the message and marks the problem in the text.
- A document can have no text. The pane then tells which part has no text form, and why. The cards still work.
- The text has the operators `+`, `*` and `>`, and the forms `if`, `list`, `seq`, `pure`, `log` and `write`. A bare name, for example `price`, reads a name of the context.

The JSON under the picture is the document. Change it, and the picture changes.
