<Playground client:load />

## How to build

1. Select a starting document, or keep the one that is there.
2. Select a card. The panel shows its kind, its value and its name.
3. Change the kind to replace the card with a new document of that kind.
4. Select **Add a part** to add a part to a list. Select **Put in a list** to nest the card one level deeper.
5. Select **Step through it** to see each event of the evaluation.

The JSON under the picture is the document. Change it, and the picture changes.
